# 排班模拟器快捷键与鼠标操作

## 生效范围

这些操作只修改干员槽位及干员状态，不把布局、队列结构、队列字段或产物设置当作干员快捷键目标。

快捷键目标按以下顺序确定：

1. 当前选中的槽位。
2. 当前鼠标悬停的槽位。
3. 两者都没有时，除撤销和重做外不执行操作。

导航和全选不使用上次操作槽位作为回退锚点。

空槽位也是有效的选中、悬停和粘贴目标。名称输入框获得焦点后，文本编辑行为优先于槽位快捷键。

## 键盘快捷键

| 快捷键                 | 功能                                                                                                                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ctrl/Cmd + A           | 第一次选择当前队列的当前设施全部槽位；第二次选择该设施的全部队列槽位；第三次选择全部设施、全部队列槽位。空槽位也会选中。第三次之后继续保持全局全选，其他选择、导航、拖动、编辑提交或历史操作会重置循环。没有选中或悬停目标时不生效。 |
| Tab                    | 在当前队列中按设施和槽位顺序移动，移动到末尾后循环到开头。                                                                                                                                                                           |
| Enter                  | 移动到下一个队列的同设施。优先选择该队列同设施的第一个空槽位；如果已全部有干员，则选择对应的槽位。                                                                                                                                   |
| ArrowLeft / ArrowRight | 在当前队列的设施和槽位顺序中向前或向后移动，到边界后停留。                                                                                                                                                                           |
| ArrowUp / ArrowDown    | 在队列之间移动对应槽位；到队列边界后进入相邻设施并钳制到可用槽位，到全局边界后停留。                                                                                                                                                 |
| Delete                 | 删除选中的干员；没有选中槽位时删除悬停槽位中的干员。选中或悬停为空槽位时不回退到其他槽位。中间空槽位保留，末尾连续空槽位才裁剪。                                                                                                     |
| Ctrl/Cmd + C           | 复制选中的槽位；没有选中槽位时复制悬停槽位。支持跨队列和跨设施多选，保留干员名称、状态和空白单元；复制内容可粘贴到其他排班表。复制后保留选中框与来源移动虚线，可以重复粘贴。 |
| Ctrl/Cmd + X           | 剪切选中的槽位；没有选中槽位时剪切悬停槽位。支持跨排班表粘贴；来源槽位立即清空但保留选中框和剪切来源移动虚线，成功粘贴后清除剪贴板和来源高亮。                                             |
| Ctrl/Cmd + V           | 从选中槽位开始，否则从悬停槽位开始粘贴。可在当前排班表或切换后的其他排班表中粘贴，沿目标队列中当前设施的目标位置和后续设施顺序写入；到该队列末尾后，超出部分截断。复制的空白单元会清空对应目标槽位。 |
| Ctrl/Cmd + Z           | 撤销最近一条排班表修改。干员、布局、队列、产物及其他排班表修改都进入历史；名称输入框获得焦点时交给文本撤销。                                                                                                                         |
| Ctrl/Cmd + Y           | 重做最近撤销的排班表修改；名称输入框获得焦点时交给文本重做。                                                                                                                                                                         |
| Escape                 | 清除复制或剪切剪贴板及其来源移动虚线，不清除当前选中框；同时关闭干员菜单。                                                                                                                                                           |

按下一个普通字符且只选中一个槽位时，会用该字符替换名称并进入名称编辑。双击槽位也会进入名称编辑。名称编辑中：

- Enter 或 Tab 提交名称，然后按对应的槽位导航规则移动。
- Delete、方向键、Ctrl/Cmd + A/C/X/V/Z/Y 和其他文本操作作用于名称文本。
- 中文输入法候选期间不会触发槽位导航。
- 空名称表示清空旧槽位，重复名称允许保存。

## 鼠标操作

- 鼠标悬停在干员或空槽位时，整个槽位显示悬停高亮。
- 左键单击槽位只选中该槽位。
- Ctrl/Command + 左键可以增减不连续的多选槽位。
- Shift + 左键在同一设施实例内按“队列为行、槽位为列”选择矩形范围，可跨队列并包含空槽位。
- 在设施队列卡片的空白区域或槽位上按住左键拖动，可以框选矩形覆盖到的所有槽位；不设置最小拖动距离。标题、按钮、输入控件和效率区域不会启动框选，浏览器不会选中页面文字。
- 按住 Shift 从有干员的槽位拖动，可以拖动当前选区。选区内的槽位作为单元格一起交换，空单元也保留；同一设施实例内跨队列时保留队列和槽位的相对位置，跨设施时按设施网格的显示顺序对应。源范围和目标范围重叠时按整体搬运顺序处理。拖到空槽位等价于移动，拖到有干员的槽位等价于交换，跨设施拖动允许。
- 复制或剪切后，来源移动虚线始终与内部剪贴板绑定；切换排班表时保留剪贴板并清除当前页面高亮，切回来源排班表时恢复仍存在的来源地址标记。再次复制或剪切、Escape 或剪切粘贴成功会清除剪贴板；来源排班表被修改或删除不会使快照失效。
- 跨排班表粘贴沿用当前目标映射规则：同一逻辑设施保留队列和槽位的相对位置，跨设施或无法匹配时按目标队列显示顺序线性写入。剪贴板数据只在当前模拟器页面内有效，不跨刷新或浏览器标签页共享。

纯选中、框选、复制不会产生历史；删除、剪切清空、粘贴、Shift 拖动交换、名称提交以及布局、队列和产物修改各产生一条历史记录。
